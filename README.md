# 🧭 NaviGo – Smart Navigation System

NaviGo is a web-based smart navigation system that helps users find routes between locations and discover nearby essential places.

## 🚀 Features

- 📍 Starting Location
- 🎯 Destination Search
- 📡 Use My Live Location
- 🗺️ Interactive Map
- 🛣️ Route Finding
- 📏 Distance Calculation
- ⏱️ Estimated Travel Time
- 🔀 Alternative Routes
- 🏥 Nearby Hospitals
- ⛽ Nearby Petrol Stations
- 🍽️ Nearby Restaurants
- 💡 Smart Route Recommendation
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Leaflet.js

## 🌐 APIs Used

- Nominatim – Location Search
- OSRM – Route Calculation
- Overpass API – Nearby Places
- ArcGIS – Map Tiles
